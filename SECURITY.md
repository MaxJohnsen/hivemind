# Security

Homing is built to keep one client's information away from another, so a security problem matters more than most bugs.

If you find one, please report it privately through [GitHub's vulnerability reporting](https://github.com/MaxJohnsen/homing/security/advisories/new), not in a public issue.

Homing's guarantees cover everything that goes through Homing, not someone with access to the server itself, such as its database or command line. The [specification](docs/spec.md#guarantees) says more.

Homing isn't ready for production use yet, so there are no supported releases.
